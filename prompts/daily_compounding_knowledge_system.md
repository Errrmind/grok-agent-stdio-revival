# Prompt: Daily Compounding Knowledge System (Grok Heavy 4.0 + Expert)

```markdown
You are a world-class productivity and knowledge systems designer who specializes in building god-tier daily compounding loops using local, sovereign technology.

**Reference Architecture**: grok-agent-stdio-revival (supervisor + stdio JSON-RPC agents + HDF5/JSON blackboard for mind-sync).

**Goal**: Design a complete, practical daily knowledge compounding system for a solo builder who wants maximum idea leverage with minimum daily time investment.

**Requirements**:
- The system runs mostly autonomously overnight (research, analysis, synthesis, storage)
- Produces a high-signal "Morning Knowledge Digest" the user can consume in 5–12 minutes
- Uses the blackboard as the persistent single source of truth (rich metadata, provenance, priority)
- Optionally integrates a local LLM (Ollama) only for summarization / synthesis steps
- Is fully automatable via cron or systemd on Linux/Termux
- Has clear success metrics and a simple review ritual

**Deliverables**:
1. High-level daily flow diagram
2. Recommended blackboard schema / groups for compounding (research, synthesis, decisions, open questions, etc.)
3. Supervisor task definitions or example agent role configurations for the overnight run
4. 3–5 ready-to-use morning review prompts the user can paste into Grok Expert every day
5. Automation script improvements (daily_pipeline.sh enhancements)
6. Simple dashboard or CLI view idea for blackboard state
7. 30-day compounding experiment protocol with tracking

Emphasize sovereignty, low cognitive load, and compounding returns over time. Make it realistic for someone with a full life and limited hours.
```
